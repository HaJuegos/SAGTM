# Guias de Contribución para SAGTM

¡Gracias por considerar contribuir a **SAGTM**! Como proyecto bajo licencia Copyleft (GPL-3.0), todas las contribuciones ayudan a mantener el software libre y abierto para la comunidad.

## ¿Cómo puedo contribuir?

### 1. Reportar Errores (Bugs)

- Revisa primero la pestaña de **Issues** en GitHub para asegurarte de que el problema no haya sido reportado.
- Si no existe, abre un nuevo Issue incluyendo:
    - Una descripción clara del problema.
    - Pasos para reproducirlo.
    - Entorno de trabajo (Versión de PHP, Laravel, navegador, etc.).

### 2. Proponer Mejoras o Nuevas Funcionalidades

- Abre un Issue con la etiqueta `enhancement` explicando qué te gustaría ver y por qué beneficia al sistema de gestión de turnos.

### 3. Enviar Código (Pull Requests)

1. Haz un **Fork** del repositorio.
2. Crea una rama para tu característica: `git checkout -b feature/nueva-funcionalidad`.
3. Asegúrate de seguir las convenciones de código de Laravel (PSR-12).
4. Haz commit de tus cambios: `git commit -m "feat: añade gestión de reportes"`.
5. Haz push a tu rama: `git push origin feature/nueva-funcionalidad`.
6. Abre un **Pull Request** detallando los cambios realizados.
