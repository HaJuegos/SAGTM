# Política de Seguridad

## Versiones Soportadas

Actualmente, solo se brindan parches de seguridad para la última versión en desarrollo:

| Versión | Soportada          |
| ------- | ------------------ |
| v0.x.x  | :white_check_mark: |

## Reportar una Vulnerabilidad

Si descubres un problema o falla de seguridad dentro de **SAGTM**, por favor **NO** abras un Issue público.

En su lugar:

1. Notifica directamente al mantenedor del proyecto vía correo electrónico o mediante un reporte privado en GitHub.
2. Proporciona detalles suficientes para reproducir la vulnerabilidad.
3. Se revisará el reporte y se emitirá una solución lo antes posible.
